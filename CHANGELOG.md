# Changelog

## 0.1.0

-  Initial release of OTPin.
-  **Orbital Style** — Digit fields orbit in a circle during
  verification, converge to a success icon on success, and shake on
  error.
-  **Cascade Style** — Cascading wave animation during verification,
  fields morph into a unified capsule on success, and staggered domino
  shake on error.
-  **Strategy Pattern** — Clean architecture that decouples visual
  styles from input logic.
-  **Full Customization** — Colors, border radii, sizes, animations,
  text styles, and success display are all configurable.
-  **Programmatic Control** — `OTPinController` for setting, clearing,
  and manually triggering states.
-  **Zero Dependencies** — Built entirely with Flutter's built-in
  animation primitives.
